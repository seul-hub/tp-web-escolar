# Pagina_web_escolar - Técnica Nº 7

##  Descripción del Proyecto

Esta es una página web escolar desarrollada para la **Escuela Técnica Nº 7** especializada en **Programación y Multimedia**, ubicada en **Lomas de Zamora**. El sitio proporciona información completa sobre la institución, sus programas académicos, procesos de admisión y datos de contacto.

##  Características Principales

La página web incluye las siguientes secciones:

### 1.Inicio (Home)
   - Bienvenida a la institución
   - Presentación general de la escuela
   - Imagen destacada o banner principal

### 2. Galería de Imágenes
   - Fotos de las instalaciones
   - Imágenes de eventos escolares
   - Actividades y proyectos realizados

### 3. Ofertas Académicas
   - Descripción de carreras técnicas disponibles
   - Nivel educativo
   - Especializaciones en programación y multimedia

### 4. Admisiones
   - Requisitos para ingresar
   - Proceso de inscripción
   - Fechas importantes
   - Documentación necesaria

### 5. Información Institucional
   - Historia de la escuela
   - Misión y visión
   - Valores institucionales
   - Logros y reconocimientos

### 6. Contacto
   - Formulario de contacto
   - Datos de ubicación
   - Teléfono
   - Email
